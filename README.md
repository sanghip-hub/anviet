# An Việt ERP – trang mở ứng dụng

Trang mở **An Việt ERP** trên mọi trình duyệt, kể cả điện thoại đang đăng nhập tài khoản Google
(tránh lỗi "Rất tiếc, không thể mở tệp" khi mở thẳng link `script.google.com`).

Link: **https://sanghip-hub.github.io/anviet/**

Kho này chỉ chứa trang mở app (không có dữ liệu hay mã nguồn ERP). Giao diện luôn được tải bản mới nhất từ máy chủ.
